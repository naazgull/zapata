zpt::stream — mute / unmute call graph

Who calls whom on the stream's __muted flag, read left → right. Columns are the call flow: bootstrap, the callers, the zpt::polling core (the only code that flips the flag), and the core's callees & sinks. Colours are the owning module. Hover any node to trace its calls; hover any edge for the transition.

Examples excluded. The websocket provider/consumer and upnp example call sites are left out. Solid = direct call, dashed = wiring/registration, dotted = asynchronous dispatcher hop — the engine re-dispatching an event back into a handler (the loop that runs around the bottom).

Source of truth: io/stream/src/streams.cpp (zpt::polling), engines/transport/ (engine + events + call<T>), engines/runtime/src/runtime.cpp, and the network/* plugins.
